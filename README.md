# mau-plugins

Personal Claude plugin marketplace.

## Install
Claude Code:
```
/plugin marketplace add MauMau93/mau-plugins
/plugin install auto-analysis@mau-plugins
```
Claude desktop (Cowork): Customize → Plugins → add marketplace `MauMau93/mau-plugins` → install **auto-analysis**.

## Plugins
- **auto-analysis** — hypothesis-driven marketing analytics framework (see `auto-analysis/README.md`).
